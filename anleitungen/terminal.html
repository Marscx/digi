Terminal: die ersten Befehle

Das Terminal öffnen und die wichtigsten Befehle kennenlernen: wo bin ich, Ordner wechseln, einen Testserver starten, den Zustand von Git ansehen. Die Grundlage für die Anleitung «Website mit Git».

  • Zeitca. 30–45 Minuten
  • Schwierigkeitleicht bis mittel
  • GerätComputer (Mac oder Windows)
  • Kostengratis, nichts zu installieren

Entwurf Noch nicht von Hand getestet. Falls ein Menü anders heisst, gilt, was du auf dem Bildschirm siehst. Sag es Marc, dann wird die Anleitung korrigiert.

Vorab einrichtenNichts zu installieren. Auf dem Mac ist das Terminal schon da, unter Windows nimm PowerShell. Lege einen Ordner mit ein paar Dateien zum Üben bereit. So bleibt am Praxistag mehr Zeit zum Ausprobieren.

1

Basics: Was ist das, was brauche ich?

5 Min.

Das Terminal ist ein Fenster, in dem du dem Computer mit Text Befehle gibst, statt mit der Maus zu klicken. Für Websites brauchst du es vor allem für drei Dinge: einen Testserver starten, mit Git arbeiten und Programme starten, die ohne Knöpfe laufen. Du brauchst dafür nur wenige Befehle.

Das brauchst du

  • Einen Computer mit Mac (das Programm «Terminal» ist schon da) oder Windows (nimm «PowerShell», ebenfalls schon da)
  • Einen Ordner mit ein paar Dateien zum Üben, am besten deine Website aus der Anleitung Website mit Git
  • Etwas Mut: Die Befehle auf dieser Seite löschen nichts (siehe die Warnung unten)
Nicht alles eintippen, was dir jemand gibtBefehle im Terminal wirken sofort und fragen oft nicht nach. Lösche nie etwas mit einem Befehl (rm, del), den du nicht verstehst. Das gilt auch für Befehle einer KI oder aus dem Internet: Lass sie dir erst erklären. Gib im Terminal nie ein Passwort ein, das du sonst nirgends brauchst, und in einen KI-Chat nie ein Passwort.
2

Das Terminal öffnen

5 Min.

Mac

  1. Drücke Cmd+Leertaste (Spotlight), tippe Terminal und drücke die Eingabetaste.
  2. Es öffnet sich ein Fenster mit einer Zeile, die auf % oder $ endet. Dahinter schreibst du deine Befehle.

Windows

  1. Drücke die Windows-Taste, tippe PowerShell und drücke die Eingabetaste.
  2. Wenn du später Git installiert hast, steht dir auch Git Bash zur Verfügung. Die Befehle unten gehen in beiden.
So funktioniert esDu tippst einen Befehl und drückst die Eingabetaste. Das Terminal antwortet mit Text oder gar nicht, wenn alles gut ging. Mit der Pfeiltaste nach oben holst du den letzten Befehl zurück, mit der Tab-Taste ergänzt es einen angefangenen Namen, mit Ctrl+C brichst du einen laufenden Befehl ab.
3

Die ersten Befehle: wo bin ich, was ist hier?

15 Min.

Tippe die Befehle nacheinander ein und schau, was passiert. Alles hier verändert nichts an deinen Dateien.

pwd

pwd zeigt, in welchem Ordner du gerade bist (Windows PowerShell: geht auch).

ls

ls listet die Dateien und Ordner in diesem Ordner (unter Windows geht auch dir).

cd Documents

cd wechselt in einen Ordner. Der Ordner muss hier liegen, sonst gibt es eine Fehlermeldung. Der Ordner heisst im Terminal Documents, auch wenn der Finder «Dokumente» zeigt. Schau mit ls nach.

cd ..

cd .. geht einen Ordner nach oben.

cd ~

cd ~ geht in deinen persönlichen Ordner (Home).

mkdir meine-website

mkdir legt einen neuen Ordner an.

cd "Mein Ordner"

Ordner mit Leerzeichen im Namen schreibst du in Anführungszeichen. Am einfachsten ist es, Ordner ohne Leerzeichen anzulegen.

clear

clear räumt das Fenster auf.

Den Ordner im Finder oder Explorer öffnen

  • Mac: open . öffnet den aktuellen Ordner im Finder.
  • Windows: explorer . öffnet ihn im Explorer.
Der PunktDer Punkt . steht für «dieser Ordner», zwei Punkte .. für «der Ordner darüber».
4

Die Befehle für deine Website

15 Min.

Diese Befehle brauchst du in der Anleitung Website mit Git. Hier siehst du sie in Ruhe, bevor du sie dort einsetzt.

Testserver starten

cd meine-website
python3 -m http.server 8000

Der Testserver liefert die Seite aus deinem Ordner aus. Öffne im Browser http://localhost:8000. Beenden mit Ctrl+C. Auf Windows heisst der Befehl meist py -m http.server 8000.

Git ansehen (ändert nichts)

git --version
git status
git log --oneline
  • git --version zeigt, ob Git installiert ist und welche Version.
  • git status zeigt, was sich seit der letzten gespeicherten Fassung geändert hat.
  • git log --oneline listet alle gespeicherten Fassungen. Mit q verlässt du die Liste.

Eine Fassung speichern und hochladen

git add .
git commit -m "Beschreibung der Änderung"
git push
  • git add . merkt alle geänderten Dateien vor.
  • git commit -m speichert eine Fassung mit einer kurzen Beschreibung.
  • git push lädt die Fassung zu GitHub hoch.
Fehlermeldung?Wenn ein Befehl eine Fehlermeldung zeigt, kopiere den ganzen Text und lass ihn dir von der KI erklären. Gib in den Chat keine Passwörter ein.
5

Kleine Umsetzung: Ordner anlegen und Testserver starten

15 Min.

Auftrag: Lege im Terminal einen Ordner an, schreibe eine Seite hinein und zeige sie im Browser.

  1. Öffne das Terminal und wechsle mit cd an den Ort, an dem du arbeiten willst (zum Beispiel cd ~).
  2. Lege den Ordner an: mkdir meine-website, dann wechsle hinein: cd meine-website.
  3. Öffne den Ordner mit open . (Mac) oder explorer . (Windows).
  4. Speichere in dem Ordner mit einem Texteditor eine Datei index.html mit einem Satz Text (oder lass dir von einer KI eine kleine Seite schreiben).
  5. Starte den Testserver: python3 -m http.server 8000 (Windows meist py -m http.server 8000).
  6. Öffne http://localhost:8000 im Browser. Siehst du deine Seite?
  7. Beende den Server mit Ctrl+C.

Fertig, wenn…

Wenn du weitermachen willst

  • Mach weiter mit der Anleitung Website mit Git veröffentlichen.
  • Frag die KI, was ein Befehl bedeutet, bevor du ihn eingibst. Sie erklärt dir jede Zeile.
!

Stolpersteine

  • «command not found» oder «nicht erkannt»: Das Programm ist nicht installiert oder du hast dich vertippt. Bei python3 unter Windows probiere py.
  • Falscher Ordner: Prüfe mit pwd und ls, wo du bist. Die meisten Fehler kommen daher, dass du im falschen Ordner bist.
  • Leerzeichen im Ordnernamen: Setze den Namen in Anführungszeichen oder benenne den Ordner ohne Leerzeichen.
  • Löschen: Befehle wie rm oder del löschen ohne Papierkorb. Nutze sie nur, wenn du genau weisst, was sie tun.
  • Der Server läuft weiter: Ein Testserver läuft, bis du ihn mit Ctrl+C beendest. Schliesse ihn, wenn du fertig bist.
  • Passwörter: Gib im Terminal und in einem KI-Chat nie ein Passwort ein, das du anderswo brauchst.
